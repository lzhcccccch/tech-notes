# 知识地图

<p class="article-meta">根据现有 Markdown 文件名归纳出的新版内容结构。</p>

这套结构不复刻旧目录编号，而是按学习路径与解决问题时的检索习惯组织。

## 七个知识域

1. **编程基础**：语言本身、集合、并发、运行时与脚本。
2. **应用开发**：框架能力、服务集成、认证和业务流程。
3. **数据工程**：数据库机制、SQL 场景与搜索分析系统。
4. **基础设施**：容器、中间件、操作系统与网络。
5. **AI 工程**：LLM 应用、Agent、RAG 与知识库。
6. **架构与质量**：设计建模、性能故障与工程工具链。
7. **栈外阅读**：读书笔记与技术之外的长期思考。

## 归档规则

- 每篇文章选择一个最符合主要问题的目录。
- 跨主题关系通过链接和标签表达，不重复保存正文。
- “原理”和“实践”分开：稳定机制进入原理专题，具体事故进入性能与故障专题。
- 未命名、草稿和待整理内容先进入收件区，整理完成后再发布。
