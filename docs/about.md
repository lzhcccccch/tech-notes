# 关于本站

<p class="article-meta">一个用于沉淀技术判断与实践经验的长期知识库。</p>

Tech Notes 希望解决一个简单问题：做过的调试、读过的源码和验证过的方案，怎样在几个月后仍然能快速复用？

## 内容原则

1. **从问题出发**：先描述真实场景和约束，再讨论方案。
2. **记录选择过程**：不仅写“怎么做”，也写“为什么这样做”。
3. **保留验证方式**：命令、测试或可观察结果应能帮助读者复现。
4. **持续修订**：发现结论过时或不完整时，直接通过 GitHub 更新。

## 技术实现

本站内容以 Markdown 保存在 GitHub 中，Docsify 在浏览器中完成渲染，GitHub Actions 自动部署到 GitHub Pages。文章底部的编辑链接可以直接发起修改；启用 Giscus 后，讨论数据会保存在 GitHub Discussions 中。
